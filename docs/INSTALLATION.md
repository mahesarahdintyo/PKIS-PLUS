# 📥 Panduan Instalasi Lokal

Dokumen ini menjelaskan langkah-langkah untuk menyiapkan dan menjalankan **Futaba PKIS** di lingkungan pengembangan lokal.

---

## 📋 Prasyarat

| Software | Versi | Keterangan |
|---|---|---|
| **Node.js** | v18+ | Direkomendasikan versi LTS terbaru |
| **npm** | v9+ | Sudah termasuk dengan Node.js |
| **Akun Supabase** | — | Diperlukan untuk database & storage |

## 🚀 Langkah Setup

### 1. Clone & Install Dependencies

```bash
git clone https://github.com/mahesarahdintyo/Futaba-Project.git
cd Futaba-Project
npm install
```

### 2. Konfigurasi Environment Variables

Buat file `.env.local` di root proyek:

```env
# Supabase API (Settings > API di dashboard Supabase)
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key

# Service Role Key (untuk operasi backend)
SUPABASE_SERVICE_ROLE_KEY=your-supabase-service-role-key
```

---

### 3. Setup Database Supabase

Buka **SQL Editor** di dashboard Supabase dan jalankan query berikut secara berurutan.

#### A. Tabel Dasar

##### Tabel `lands`
```sql
CREATE TABLE public.lands (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  description TEXT,
  hidden_from_operator BOOLEAN DEFAULT false,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc', now()) NOT NULL
);
ALTER TABLE public.lands ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow public read lands" ON public.lands FOR SELECT USING (true);
```

##### Tabel `folders`
```sql
CREATE TABLE public.folders (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  parent_id BIGINT REFERENCES public.folders(id) ON DELETE CASCADE,
  land_id TEXT REFERENCES public.lands(id) ON DELETE CASCADE NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc', now()) NOT NULL
);
ALTER TABLE public.folders ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow public read folders" ON public.folders FOR SELECT USING (true);
CREATE POLICY "Allow public write folders" ON public.folders FOR ALL USING (true) WITH CHECK (true);
```

##### Tabel `categories`
```sql
CREATE TABLE public.categories (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT UNIQUE NOT NULL,
  description TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc', now()) NOT NULL
);
INSERT INTO public.categories (name, description) VALUES
  ('SOP', 'Standard Operating Procedures'),
  ('Manual', 'User Manuals and Guides'),
  ('Form', 'Forms and Templates'),
  ('Lainnya', 'Other Documents');
```

##### Tabel `documents`
```sql
CREATE TABLE public.documents (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  title TEXT NOT NULL,
  description TEXT,
  category_id BIGINT REFERENCES public.categories(id) ON DELETE SET NULL,
  file_name TEXT NOT NULL,
  file_path TEXT NOT NULL,
  file_size BIGINT,
  file_type TEXT,
  uploaded_by TEXT,
  target_time TIMESTAMP WITH TIME ZONE,
  hidden_from_operator BOOLEAN DEFAULT false NOT NULL,
  folder_id BIGINT REFERENCES public.folders(id) ON DELETE CASCADE,
  land_id TEXT REFERENCES public.lands(id) ON DELETE CASCADE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc', now()) NOT NULL,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc', now()) NOT NULL
);
ALTER TABLE public.documents ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow public read documents" ON public.documents FOR SELECT USING (true);
CREATE POLICY "Allow public write documents" ON public.documents FOR ALL USING (true) WITH CHECK (true);
```

##### Tabel `land_display_documents`
```sql
CREATE TABLE public.land_display_documents (
  land_id TEXT PRIMARY KEY REFERENCES public.lands(id) ON DELETE CASCADE,
  document_id UUID REFERENCES public.documents(id) ON DELETE SET NULL,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc', now()) NOT NULL
);
ALTER TABLE public.land_display_documents ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow public access land_display_documents" ON public.land_display_documents FOR ALL USING (true) WITH CHECK (true);
```

#### B. Tabel Laporan Produksi

Jalankan file `supabase/migrations/20260708_create_production_reports.sql` atau query berikut:

```sql
CREATE TABLE public.production_reports (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  land_id UUID REFERENCES public.lands(id) ON DELETE CASCADE NOT NULL,
  report_date DATE NOT NULL DEFAULT CURRENT_DATE,
  shift TEXT NOT NULL,

  start_time TIME NOT NULL,
  end_time TIME NOT NULL,
  part_number TEXT NOT NULL,

ALTER TABLE public.production_reports ENABLE ROW LEVEL SECURITY;

```

#### E. Migrasi Tambahan

Terapkan semua file SQL di folder `supabase/migrations/` secara berurutan (sesuai tanggal di nama file) ke SQL Editor Supabase.

#### F. Aktifkan Supabase Realtime

Beberapa halaman memakai Supabase Realtime agar data lintas perangkat langsung tersinkron tanpa refresh manual:

- `production_reports`: laporan baru dari operator langsung muncul di dashboard admin.
- `part_numbers`: dropdown part number operator langsung mengikuti tambah/hapus dari admin.

Aktifkan melalui dashboard Supabase: **Database** -> **Replication** -> publication `supabase_realtime`, lalu enable tabel `production_reports` dan `part_numbers`.

Atau jalankan SQL berikut:

```sql
ALTER PUBLICATION supabase_realtime ADD TABLE public.production_reports;
ALTER PUBLICATION supabase_realtime ADD TABLE public.part_numbers;
```

Jika tabel sudah pernah ditambahkan ke publication, Supabase dapat menampilkan error duplikat; itu aman diabaikan.

### 4. Setup Storage Bucket

1. Buka menu **Storage** di dashboard Supabase.
2. Buat bucket baru bernama **`documents`**.
3. Set bucket sebagai **Public**.
4. Buat policy akses:
   - **Read**: Allow for `public` (semua orang)
   - **Insert/Delete**: Allow for `authenticated` (hanya user login)

---

### 5. Buat User Admin

Di dashboard Supabase → **Authentication** → **Users** → **Invite User** atau **Add User**:
1. Tambah email & password user admin.
2. Di SQL Editor, update role di tabel `profiles`:
```sql
UPDATE public.profiles SET role = 'admin' WHERE email = 'admin@example.com';
```

### 6. Jalankan Aplikasi

```bash
# Development

```
